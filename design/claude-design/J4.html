Résultat de manche

Trois temps de lecture, toujours dans le même ordre : le verdict (une ligne), les points gagnés (le plus gros chiffre de l'écran), puis la bonne réponse — affichée même quand le joueur a juste. Le détail base / bonus / série se déplie au-dessous.

Règle absolue tenue ici : aucun rang, aucune position chiffrée, aucun classement. Le seul repère de position est le déplacement — ▲ +2 places, ▼ −1 place ou « stable ».
