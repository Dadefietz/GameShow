Panneau de connexion

Bloc permanent de la colonne droite, identique dans les quatre phases de jeu. Il reprend pièce par pièce le vocabulaire du système, à l'échelle de diffusion : la capsule d'identité du joueur pour le salon, le champ creusé de la saisie de code (fond enfoncé, sh-inset, monospace espacé) pour le code lui-même, et la marque animée en tête.
